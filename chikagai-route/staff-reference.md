# スタッフ向け参考資料｜9月19日 神戸会場 → 大阪会場

大阪会場（大阪科学技術センター 8階大ホール）に開始30分前（14:30）に到着したいスタッフ向けの参考情報です。ページ本体の「[三宮から大阪会場への移動](index.html#osaka)」とあわせてご確認ください。

## 1. 14:30着を目指す場合の出発計画

### 前提

- 研修終了：13:30
- 大阪会場（大阪科学技術センター 8階大ホール）着目標：14:30
- 研修終了を待って移動を開始すると、開始に間に合わない可能性が高い
- 14:00に三宮会場を出る計画では間に合う前提にできない
  - JR新快速でも三ノ宮〜大阪は約21分
  - 13:52発の新快速では本町着14:26となり、会場までの徒歩を含めると余裕がない

### 先行組・荷物担当を分ける

**先行組**
- 13:15〜13:20ごろに会場を出発
- 受付に必要な最小限の荷物だけ持ち、ICカードを準備
- 目標：13:37 三ノ宮発の新快速（会場出発時刻は徒歩・改札・ホーム移動の余裕を見た計画値）

**荷物・片付け組**
- 段差を避け、荷物量と必要な介助に応じて駅からのタクシー、会場間の車移動も検討
- 14:00発なら、到着担当を先行組へ
- 車も渋滞・配車待ちがあり30分到着は保証できない
- 荷物担当も14:30必着なら撤収分担・終了時刻の調整が必要

### 先行組の接続例（JRの場合、9月19日）

| 時刻 | 内容 |
|---|---|
| 13:15〜13:20 | 三宮会場を出発 |
| 13:37 | 三ノ宮発（新快速・長浜行） |
| 13:58 | 大阪着 → 徒歩で西梅田 |
| 14:14 | 西梅田発（四つ橋線・住之江公園行） |

### 阪神利用の場合

- 大阪梅田駅から西梅田駅への乗り換えが分かりやすい（同じ地下街内）
- 大阪梅田まで約31〜32分（特急・直通特急、大阪難波・奈良方面行きとは区別）
- JRより車内時間が長いため、14:30必着の先行組は当日の接続を含めて判断

### 大阪駅からタクシーを使う場合

- 目的地：大阪科学技術センター、靱本町1丁目8-4
  - ※大阪市立科学館とは別施設
- 乗り場を探す時間・待ち列・道路混雑を含めて比較
- 乗り場の位置と当日の待ち時間は未確認のため「最速」とは断定できない
- 採用する場合は出発前に乗り場を一つ決めて共有

## 2. 階段を避けるルート（車いす・段差回避が必要な方向け）

### 大阪駅から西梅田駅（段差を避けるルート）

1. JRホームのEVから、段差なしで通れる「南口改札」へ。改札を出て地上1階を桜橋口方面へ歩く
2. 西梅田駅北側、ハービスENT側の4-A出入口付近にある地上EVへ（コンコース階〜B1F〜地上のEV）
3. 地下に降りたら、北改札には入らず改札外の北コンコースを南へ。西梅田の「南改札」から入り、ホーム行きEVで降りる

- 通常の桜橋口・階段経路より遠回り
- 14:14の地下鉄への接続を保証する経路ではない
- 公式案内：<https://subway.osakametro.co.jp/station_guide/Y/y11/index.php>

### 本町駅（階段を避けて地上へ）

- 西梅田から到着する1番線ホーム → 北東改札 → 26号出入口EV → 地上へ
- 四つ橋筋の東側に出るため、横断歩道で西側へ渡り、会場方面へ北上
- 28号出口の徒歩5分に、EV待ちや横断の時間を加える
- 公式案内：<https://subway.osakametro.co.jp/station_guide/Y/y13/index.php>

### 肥後橋駅（階段を避けて地上へ）

- 公式案内：<https://subway.osakametro.co.jp/station_guide/Y/y12/index.php>

## 3. 各社の梅田駅から西梅田駅までのアクセス

各社の梅田駅から西梅田駅（Osaka Metro 四つ橋線）までの徒歩ルート。**乗り換えの分かりやすさは、阪神＞JR＞阪急の順**。

| 経路 | 所要時間 | 特徴 |
|---|---|---|
| 阪神大阪梅田駅 → 西梅田 | 最短 | 同じ地下街内を移動、乗り換えが分かりやすい |
| JR大阪駅 → 西梅田 | 徒歩5〜7分 | 桜橋口から地上へ出て徒歩、経路はやや複雑 |
| 阪急大阪梅田駅 → 西梅田 | やや距離あり | 地上・地下を経由 |
