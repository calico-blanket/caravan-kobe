# 神戸キャラバン現地レポート

## 開き方

ZIPをすべて展開して、index.htmlをブラウザで開いてください。インストールやビルドは不要です。本文・写真はオフラインでも表示できます。X投稿の埋め込み表示と外部の出典リンクには通信が必要です。

## ファイル構成

- index.html：本文、X投稿の埋め込み、写真の説明、出典
- css/style.css：配色、文字、余白、スマホ・PCの配置
- js/main.js：写真の拡大と閉じる操作のみ
- images/：提供写真11枚（本文には9枚を選定）
- SOURCES.md：出典と写真ファイルの対応表

## 編集方法

各ファイルの番号付きコメントで、編集するセクションを探してください。文字コードはUTF-8です。

1. 文章：index.htmlの該当する見出しやp要素を編集します。
2. 投稿：machine-embedのarticle全体が1件の埋め込みです。対応する元投稿URLを変更するときは、必ず実在する投稿と照合してください。
   Threadsの参加記録は `voice-threads-fumichi` の `article` 全体が1件です。掲載許可を得た本文を折りたたまず表示します。
3. 写真：imgのsrcと、その外側のaのhrefを同じ写真ファイルにします。altには写真の説明、figcaptionには画面に表示する説明を入れます。画像のwidth/heightも実際の比率に合わせてください。
4. 色：css/style.css冒頭の変数を変更します。--greenがリンク等の濃い緑、--paleが薄い背景色です。
5. 拡大機能を外す：HTMLのscript行を削除しても本文は読めます。写真は通常のリンクとして開けます。

## 内容の扱い

2026年9月20日に公式開催ページ、掲載対象のX投稿12件、武藤かず子議員の追加投稿とリンク先noteを確認して作成。日時・会場・講師担当・二部構成は公式情報、会場の混雑や登壇者の発言は参加者の記録として明記しています。正確な各部開始時刻、参加人数、全発言は未確認です。兵庫についての話し合い、Slidoでの質疑、「ゆる語りワークショップ」に関する追記は依頼者の記憶に基づき、逐語録ではないことをページ内に記載しています。地理表現は「日本海と瀬戸内海」に補正しました。AI性能の数値は写真に写った説明として扱い、一般化していません。

会場写真は元画像を保存し、ページ上で一部の表示範囲を整えています。追加した配布資料2枚は背景と影を整え、QRコード・関連URL・会場接続情報を公開用に加工しています。提供者の説明に従い会場写真として使用し、画像だけから人物の本人確認はしていません。

## 配布について

ファイル一式で納品しています。Webへの公開は行っていません。HTMLだけでなくcss/js/imagesを同じ配置で配布してください。LINEでURLから開けるようにするには、別途Webサーバーへの設置が必要です。
